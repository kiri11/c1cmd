# c1 command reference

Generated by `scripts/generate.sh` from the command table in `Sources/C1Kit`; do not edit. Example results are recorded against the fake Capture One in `Tests/C1KitTests`, so their values are illustrative. `c1 <command> --help` prints the same facts.

c1 reads and edits photos in Capture One, the open Catalog or Session, through its scripting interface and database.

Arguments are one JSON object; '-' reads it from stdin. Output is compact JSON with nulls left out; --pretty indents it. Exit status: 0 for a result, including an unknown outcome; 1 for a failure, whose JSON is on stdout; 2 for a usage error, on stderr.

--document <path> reads a Catalog (.cocatalog) or Session folder's database instead of the open document, without Capture One: list, collections, contact_sheet and thumb take it.

c1 never touches originals and never deletes variants. Before its first write to a variant it saves a snapshot that revert restores.

| Command | Changes variants | Summary |
|---|---|---|
| `doctor` | no | Check Capture One, the open document and its backup; warns without blocking. |
| `list` | no | List variants from the database, filtered and paged. |
| `collections` | no | List collections with kind, parent and variant count. |
| `get` | no | Read live settings, geometry and layers of 1–100 variants. |
| `selection` | no | Read the ids of the variants selected in Capture One. |
| `set` | yes | Write absolute values to 1–100 variants: adjustments, curves, color corrections, lens correction, geometry, crop, rating, color tag, layers. |
| `action` | yes | Run a layer, mask, color, dehaze, lens or reset action on 1–100 variants. |
| `revert` | yes | Restore variants to the snapshot c1 took before its first write; scope all, adjustments, geometry, metadata or layers. |
| `preview` | no | Export a JPEG of one variant: the crop at a long edge, the full frame with a pixel mapping, or a region at a scale. |
| `crop_preview` | no | Show 1–6 candidate crops side by side, cut from a cached full-frame render; the variant is not written. |
| `contact_sheet` | no | Tile Capture One's cached thumbnails for a page of list's scope into one JPEG, without Apple Events; fillMissing exports the photos the cache lacks. |
| `thumb` | no | Read the camera's embedded JPEG of one variant's original, without Capture One's edits. |

## Failure codes

A failed call prints `{"error": {code, message, hint?, outcome?}}` and exits 1; with `outcome: unknown` it may have run in Capture One, and exits 0.

| Code | Meaning |
|---|---|
| `invalid-arguments` | The arguments are malformed or out of range; nothing was sent to Capture One. |
| `not-running` | Capture One is not running. |
| `no-document` | Capture One has no open Catalog or Session. |
| `permission-denied` | macOS refused Automation access to Capture One; allow it under System Settings > Privacy & Security > Automation. |
| `timeout` | Capture One did not answer in time; the outcome is unknown, so call get again. A first call may be waiting for the Automation consent dialog. |
| `busy` | The queue for Capture One is full, or the call waited 10 minutes for its turn. |
| `schema-mismatch` | The database lacks a table or column c1 reads: an untested Capture One build. |
| `document-changed` | The open document changed during the call; call it again. |
| `database` | The document's database could not be read. |
| `script-error` | Capture One reported a scripting error. |
| `not-found` | The variant, or its original file, is not there. |
| `internal` | A bug in c1. |

## doctor

Check Capture One, the open document and its backup; warns without blocking.

Reports c1's version, Capture One's version and whether c1 is tested on it, the open document, its last Catalog backup, and where c1 keeps its snapshots and log. Warnings never block: an untested Capture One build, a Catalog backup missing or older than a day, and scripting terms that differ from the 16.8.5.30 terms c1 is built with.

A first call from a new terminal or agent app can wait until timeout while macOS shows the Automation consent dialog, sometimes behind other windows.

### Arguments

None; pass `{}` or nothing.

### Example

```sh
c1 doctor '{}'
```

```json
{
  "c1" : {
    "version" : "dev"
  },
  "captureOne" : {
    "tested" : true,
    "version" : "16.8.5.30"
  },
  "document" : {
    "kind" : "catalog",
    "lastBackup" : "2027-01-15T07:00:00Z",
    "name" : "fixture",
    "path" : "/fixture.cocatalog",
    "uuid" : "0A1B2C3D-0000-4000-8000-000000000001"
  },
  "storage" : "~/.c1/documents/0A1B2C3D-0000-4000-8000-000000000001",
  "warnings" : [

  ]
}
```

### Errors

Failures: `not-running`, `permission-denied`, `timeout`, `busy`, `script-error`, `database`, `schema-mismatch`.

## list

List variants from the database, filtered and paged.

Reads the document's database, not Capture One, so it is fast and works with --document on a closed Catalog or Session. Results are ordered by id; next is the cursor for the following page. Ratings and color tags may lag Capture One by up to a minute, and a new document's database can lag its first minute.

### Arguments

| Name | Type | Required | Range | Values | Description |
|---|---|---|---|---|---|
| `rating` | integer | no | 0–5 |  | Only variants with exactly this rating. |
| `minRating` | integer | no | 0–5 |  | Only variants rated at least this. |
| `colorTag` | integer | no | 0–7 |  | Only variants with this color tag; 0 is none. |
| `collection` | collection id | no |  |  | Only variants in this collection (from collections); a folder includes its subfolders. |
| `ids` | list of variant id | no |  |  | Only these variants. |
| `edited` | boolean | no |  |  | Only variants whose settings differ (true) or do not differ (false) from the defaults Capture One applied at import. |
| `after` | variant id | no |  |  | Paging cursor: the next value of the previous page. |
| `limit` | integer | no | 1–1000 |  | Variants per page (default 100). |

```sh
c1 list '{"minRating":4,"limit":2}'
```

## get

Read live settings, geometry and layers of 1–100 variants.

Reads each variant through its folder, so the cost follows that folder's size, not the Catalog's: about 0.35 s, and about 1 s more for each layer other than the background. Results: variant (rating, color tag, crop and more), adjustments (with curves and colorEditor), lensCorrection, layers (the background first; other layers carry their own adjustments), cropBounds and route. changed: true keeps only the fields that differ from an unedited import, plus those that depend on the camera.

Crops are [centre x, centre y, width, height] in whole pixels of the oriented, rotated canvas, with y up from the bottom edge. get reports cropBounds: the four corners of the area a crop may cover after rotation and keystone (source image is exact; source maximumCrop, used when keystone, lens geometry or flip are set, keeps the image's proportions, so it is narrower than the true area for other ratios).

Every Capture One call from every c1 process waits in one first-in, first-out queue: at most 8 callers wait, and others fail at once with busy, as does a caller that waits 10 minutes. A crashed caller's place is released automatically.

### Arguments

| Name | Type | Required | Range | Values | Description |
|---|---|---|---|---|---|
| `ids` | list of variant id | yes | 1–100 items |  | Variant ids as strings of digits, from list, selection or contact_sheet. |
| `changed` | boolean | no |  |  | Report only fields that differ from an unedited import (default false). |

### Example

```sh
c1 get '{"ids":["1"],"changed":true}'
```

## set

Write absolute values to 1–100 variants: adjustments, curves, color corrections, lens correction, geometry, crop, rating, color tag, layers.

Values are named as get reports them and are absolute targets. Geometry (orientation, flip, keystone, rotation, lens geometry) moves cropBounds, so a crop cannot be set with it; a positive rotation turns the photo clockwise, and Capture One shrinks the crop to fit: set the geometry, read cropBounds with get, then set a crop inside it. Curves are set whole under adjustments.curves.<channel> as 2–18 [x, y] points within 0–100, more than 1.5 apart on x. Basic color corrections are named (red … all) under adjustments.colorEditor.basic; advanced ones are addressed by index under colorEditor.advanced and added with action color.create. Mask pixels cannot be read, so no snapshot holds them.

Every write reads the variant first, so a set takes about 3 s, and about 1 s more for each layer other than the background. Before c1's first write to a variant it saves the variant's full settings as a snapshot, and revert restores it; each write call is appended to a log. Both live in ~/.c1/documents/<document uuid>/. Values are absolute: give the target, not a change. c1 checks names, types and measured ranges before dispatch, then reads each field back: a stored value that differs from the one sent is a warning {field, sent, stored}, not a failure. A timeout's outcome is unknown: call get again to see the current state; c1 does not retry.

Crops are [centre x, centre y, width, height] in whole pixels of the oriented, rotated canvas, with y up from the bottom edge. get reports cropBounds: the four corners of the area a crop may cover after rotation and keystone (source image is exact; source maximumCrop, used when keystone, lens geometry or flip are set, keeps the image's proportions, so it is narrower than the true area for other ratios).

Every Capture One call from every c1 process waits in one first-in, first-out queue: at most 8 callers wait, and others fail at once with busy, as does a caller that waits 10 minutes. A crashed caller's place is released automatically.

| `ids` | list of variant id | yes | 1–100 items |  | Variant ids as strings of digits, from list, selection or contact_sheet. |

## action

Run a layer, mask, color, dehaze, lens or reset action on 1–100 variants.

c1 tags the layers it creates with " [c1:<tag>]". layer.delete, the mask actions that overwrite pixels and luma.clear run only on those layers, because revert cannot restore mask pixels or a luma range; variant.reset is refused while the variant has a layer that is not c1's, because Capture One then deletes every layer. A layer renamed in Capture One without its tag becomes the photographer's. reset applies defaults; it is not an undo: revert is.

Every write reads the variant first, so a set takes about 3 s, and about 1 s more for each layer other than the background. Before c1's first write to a variant it saves the variant's full settings as a snapshot, and revert restores it; each write call is appended to a log. Both live in ~/.c1/documents/<document uuid>/. Values are absolute: give the target, not a change. c1 checks names, types and measured ranges before dispatch, then reads each field back: a stored value that differs from the one sent is a warning {field, sent, stored}, not a failure. A timeout's outcome is unknown: call get again to see the current state; c1 does not retry.

Every Capture One call from every c1 process waits in one first-in, first-out queue: at most 8 callers wait, and others fail at once with busy, as does a caller that waits 10 minutes. A crashed caller's place is released automatically.

| Name | Type | Required | Range | Values | Description |
|---|---|---|---|---|---|
| `ids` | list of variant id | yes | 1–100 items |  | Variant ids as strings of digits, from list, selection or contact_sheet. |
| `action` | text | yes |  | `layer.create`, `layer.delete`, `style.apply`, `mask.clear`, `mask.fill`, `mask.invert`, `mask.rasterize`, `mask.feather`, `mask.refine`, `mask.copy`, `mask.people`, `luma.clear`, `color.create`, `color.delete`, `dehaze.pick`, `dehaze.recalculate`, `lens.reset`, `variant.reset` | The action; the action table gives each one's arguments. |
| `arguments` | object of fields | no |  |  | The action's arguments. |

## revert

Restore variants to the snapshot c1 took before its first write; scope all, adjustments, geometry, metadata or layers.

Restores the snapshot c1 took before its first write to each variant: deletes the tagged layers created since, and restores every other layer and the background. Later edits in Capture One to that variant are overwritten. A snapshot layer that no longer exists is reported as not restored. After a complete revert of scope all, the snapshot is deleted and the next write takes a fresh one; a revert with errors, warnings or notRestored entries keeps it, so revert can run again. Scopes: adjustments (tone, color, curves, lens), geometry (rotation, keystone, orientation, flip, crop), metadata (rating, color tag), layers.

Every Capture One call from every c1 process waits in one first-in, first-out queue: at most 8 callers wait, and others fail at once with busy, as does a caller that waits 10 minutes. A crashed caller's place is released automatically.

### Arguments

| Name | Type | Required | Range | Values | Description |
|---|---|---|---|---|---|
| `ids` | list of variant id | yes | 1–100 items |  | Variant ids as strings of digits, from list, selection or contact_sheet. |
| `scope` | text | no |  | `all`, `adjustments`, `geometry`, `metadata`, `layers` | What to restore (default all). |

```sh
c1 revert '{"ids":["1"],"scope":"adjustments"}'
```

## preview

Export a JPEG of one variant: the crop at a long edge, the full frame with a pixel mapping, or a region at a scale.

The default is the variant's crop at a long edge of size px (1.1–2 s). fullFrame renders the default crop instead (Capture One's largest centred rectangle) and maps it: mapping {scale, left, top} turns crop pixels into render pixels as x' = (x − left) × scale, y' = (top − y) × scale, and currentCrop and cropBounds are given in render pixels. region renders a part of the cropped preview at scale × full resolution, for judging detail; the result gives the region in crop pixels. The variant is not written: c1 exports through its c1-preview recipe.

A Catalog whose output folder is unset refuses every export, so c1 sets it to its preview folder and warns.

JPEGs land in ~/Library/Caches/c1/previews/<document uuid>/; c1 deletes its previews older than 7 days.

Every Capture One call from every c1 process waits in one first-in, first-out queue: at most 8 callers wait, and others fail at once with busy, as does a caller that waits 10 minutes. A crashed caller's place is released automatically.

### Arguments

| Name | Type | Required | Range | Values | Description |
|---|---|---|---|---|---|
| `id` | variant id | yes |  |  | One variant id as a string of digits. |
| `size` | integer | no | 200–3000 |  | Long edge in px (default 1500); not with region. |
| `fullFrame` | boolean | no |  |  | Render the default crop with a pixel mapping (default false). |
| `region` | object {x, y, width, height} | no |  |  | A part of the cropped preview, as fractions from its top left. |
| `region.x` | number | yes | 0–1 |  | Left edge, as a fraction of the cropped preview's width from its left. |
| `region.y` | number | yes | 0–1 |  | Top edge, as a fraction of the cropped preview's height from its top. |
| `region.width` | number | yes | 0–1 |  | Width as a fraction; x + width ≤ 1. |
| `region.height` | number | yes | 0–1 |  | Height as a fraction; y + height ≤ 1. |
| `scale` | number | no | 0.05–1 |  | With region: the render's scale of full resolution (default 1). |
| `timeout` | number | no | 1–600 |  | Seconds to wait for the exported JPEG (default 120). Past it the outcome is unknown and the result names where the file will land. |

### Example

```sh
c1 preview '{"id":"1","size":800}'
```


### Errors

Failures: `invalid-arguments`, `not-found`, `not-running`, `no-document`, `permission-denied`, `timeout`, `busy`, `document-changed`, `script-error`, `database`, `schema-mismatch`.

## crop_preview

Show 1–6 candidate crops side by side, cut from a cached full-frame render; the variant is not written.

Candidates are rectangles in crop pixels, each checked against cropBounds. They are cut from a full-frame render that is cached until a setting other than the crop or metadata changes (about 0.5 s from cache). The render shows only the default crop, Capture One's largest centred rectangle, so a candidate beyond it fails: try it with set, preview and revert instead.

Crops are [centre x, centre y, width, height] in whole pixels of the oriented, rotated canvas, with y up from the bottom edge. get reports cropBounds: the four corners of the area a crop may cover after rotation and keystone (source image is exact; source maximumCrop, used when keystone, lens geometry or flip are set, keeps the image's proportions, so it is narrower than the true area for other ratios).

A Catalog whose output folder is unset refuses every export, so c1 sets it to its preview folder and warns.

JPEGs land in ~/Library/Caches/c1/previews/<document uuid>/; c1 deletes its previews older than 7 days.

## contact_sheet

Tile Capture One's cached thumbnails for a page of list's scope into one JPEG, without Apple Events; fillMissing exports the photos the cache lacks.

Scope comes from list's filters or ids, paged by perPage. Tiles are justified rows at most 1536 px wide, labelled id · ★rating · name. Capture One builds thumbnails only for photos its browser has shown, so a sheet has gaps for the rest; fillMissing exports each gap at 1024 px, about 2.4 s per gap, and reuses an export until a setting other than rating or color tag changes. Ratings may lag by up to a minute.

A Catalog whose output folder is unset refuses every export, so c1 sets it to its preview folder and warns.
